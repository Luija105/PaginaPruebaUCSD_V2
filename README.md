# Servicios Academicos UCSD

> Una aplicación web modular desarrollada en ASP.NET Core / Razor Pages diseñada para ser altamente extensible y fácil de personalizar, con soporte preparado para conexión a base de datos SQL Server utilizada principalmente para procesos estudiantiles a nivel universitario

## 🚀 Características

- **Modular y extensible**: Diseñada a nivel de componentes para que sea fácil agregar nuevas funcionalidades y páginas.
- **Preparada para base de datos**: Incluye funciones e infraestructura lista para conectar e interactuar con SQL Server.
- **Responsive Design**: Interfaz optimizada para adaptarse a distintos tamaños de pantalla.

## 🛠️ Tecnologías Utilizadas

- **IDE / Entorno**: Visual Studio 2026
- **Backend / Architectura**: C# (.NET Core / ASP.NET Core Razor Pages)
- **Frontend**: HTML5, CSS3, Razor Syntax (`.cshtml`)
- **Base de Datos**: Preparado para SQL Server

## 📦 Requisitos Previos

Antes de ejecutar este proyecto localmente, asegúrate de contar con:

- [Visual Studio 2026](https://visualstudio.microsoft.com/) (con la carga de trabajo *Desarrollo de ASP.NET y web* instalada).
- [.NET SDK](https://dotnet.microsoft.com/download) correspondiente a la versión utilizada en la solución.
- [SQL Server / LocalDB](https://www.microsoft.com/sql-server) (opcional, para habilitar la funcionalidad de base de datos).
